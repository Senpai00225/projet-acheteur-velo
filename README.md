# 🚴 Projet d'analyse : acheteurs de vélos

Analyse Excel d'un jeu de données clients pour comprendre **quels profils achètent un vélo**.

## 🎯 Objectif
Identifier les facteurs qui influencent l'achat d'un vélo (revenu, âge, situation familiale, distance de trajet, région, etc.) et les présenter dans un tableau de bord clair.

## 📁 Contenu
- `Projet_acheteur_de_vélo.xlsx` : fichier Excel du projet

Le classeur contient 4 feuilles :

| Feuille | Rôle |
|---|---|
| **bike_buyer** | Données brutes (environ 1 000 clients) |
| **Data Projet Cleaning** | Données nettoyées : colonnes traduites, valeurs harmonisées, tranche d'âge ajoutée |
| **Visualisation** | Tableaux croisés dynamiques et graphiques |
| **Dashboard** | Tableau de bord final « Vente de vélo » |

## 🧹 Nettoyage des données
- Traduction des libellés (statut marital, genre) : `M` → Marié, `S` → Célibataire, etc.
- Création d'une colonne **Tranche d'âge** avec une formule `SI` (Jeune / Adulte / Vieux)
- Vérification des doublons et des valeurs manquantes

## 📊 Analyses réalisées
- Revenu moyen selon l'achat ou non d'un vélo
- Achats par tranche d'âge
- Achats selon la distance de trajet
- Tableau de bord avec filtres (segments)

## 🛠️ Outils utilisés
- Microsoft Excel : formules, tableaux croisés dynamiques, graphiques, segments
